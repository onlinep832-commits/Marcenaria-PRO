# Marcenaria PRO 2026

Sistema web progressivo (PWA) para cálculo de planos de corte, orçamentos e listagem de peças.

## Estrutura de Arquivos
- **index.html**: Estrutura principal.
- **styles.css**: Design e aparência.
- **script.js**: Lógica de cálculo e interação.
- **dados.json**: Banco de dados inicial (Materiais, Peças, Ferragens).
- **sw.js**: Script para funcionamento Offline.
- **manifest.json**: Configuração para instalação (Ícone e Nome).

## Como Instalar (PWA)
1. Abra o `index.html` no Chrome, Edge ou navegador móvel.
2. No computador: Procure um ícone de "Instalar" (+) na barra de endereço.
3. No celular (Android): Toque nos três pontos > "Adicionar à tela inicial".
4. No iPhone (iOS): Toque em Compartilhar > "Adicionar à Tela de Início".

## Funcionalidades
- Criação de módulos sob medida (Retos e de Canto).
- Cálculo automático de preço de MDF e Fita de Borda.
- Geração de PDF para Cliente (Orçamento).
- Geração de PDF para Produção (Peças).
- Exportação para Excel e Cortcloud.
- Funcionamento 100% Offline após a primeira carga.
